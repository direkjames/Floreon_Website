How to get whitelisted

Floreon is whitelist-only. Follow these steps to get in.

  1. Apply in Discord

    Join our Discord server and fill up the whitelist form. Double-check your Minecraft username and answers, because accuracy matters.

  2. Wait for approval

    The team reviews every application. You'll hear back in Discord once you're accepted.

  3. Install the modpack

    Once accepted, you'll get the modpack in our Discord. Install it, launch the game and join. Floreon is already in its server list.
